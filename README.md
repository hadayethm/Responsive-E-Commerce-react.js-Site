# 🛒 Modern eCommerce Store

[![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://react.dev/)
[![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)

A high-performance, visually stunning eCommerce frontend built with a focus on **user experience**, **clean code**, and **modern design principles**. This project was developed using React and Vite, featuring smooth animations and a fully responsive layout.

---

## ✨ Features

* **📱 Fully Responsive**: Optimized for all screen sizes (Mobile, Tablet, Desktop).
* **📂 4 Dynamic Pages**:
    * **Home Page**: Engaging hero sections and featured product sliders.
    * **Listing Page**: Dynamic product grid with filtering capabilities.
    * **Detail Page**: Deep-dive view for individual products.
    * **Cart Page**: Smooth shopping experience with real-time updates.
* **🎬 Fluid Animations**: Interactive UI powered by **Framer Motion**.
* **🤖 AI-Optimized**: Developed with AI assistance to ensure clean, efficient, and bug-free code structures.
* **⚡ Fast Performance**: Powered by Vite and Tailwind CSS for instant load times.
